# 素材關卡：從主題到合格原圖

僅在使用者只給主題、沒有原圖時啟用。目的：生出「合格原圖」後交回正式製作線。此關卡生成的是點陣圖，揭露方式一律為筆刷遮罩，不得聲稱逐筆描線。生圖工具以本機 `image-gen` 技能（OpenAI gpt-image-1）為例；其他生圖工具流程相同，只替換呼叫方式。

## 順序

1. **腳本與元件清單**：先完成旁白腳本，再依敘事拆出每幕需要的插畫元件，例如第一幕「藥瓶、箭頭、台灣地圖、問號」。每個元件記錄出現時間、位置、尺寸與揭露順序。
2. **風格基準**：先從下方預設風格中選一種，定調一組風格描述，生成一張基準圖。之後每張元件生成都沿用同一組風格描述。預設（未指定時）為手繪風線稿；但全片純黑白易顯單調，除非敘事需要（如書信、圖表），建議選帶色彩的風格或至少一個重點色。

| 預設風格 | 描述關鍵詞 | 適用 |
|---|---|---|
| 手繪風線稿（預設） | black ink line art, bold simple strokes, white background | 圖解、簡報感強的內容 |
| 平塗彩繪 | flat color illustration, warm palette, clean outlines, children's book style | 故事、兒童向、情緒溫暖的主題 |
| 淺彩鉛筆 | soft colored pencil texture, light colors, hand-drawn | 親和、教學、生活感 |
| 單重點色 | black line art with one accent color | 保留線稿利落感又不單調 |
3. **逐張生成**：帶基準圖作參考生成後續元件（image-gen `--ref`），確保線條、比例、配色一致。需要透明底的元件（手部素材、疊加插畫）加 `--transparent`。
4. **檢查與重生成**：見下方檢查清單。不合格就重生成；同一元件最多重生成 3 次，仍不合格即中止並如實回報卡關點，不得降低標準硬交。
5. **入庫與交接**：合格原圖複製進專案 `sources/`，記錄 SHA-256 與尺寸，登記 `project.json`（route 仍為 preserve），進入正式製作線（保護來源→揭露設計→手持筆→合成→驗收）。

## 無文字原則（生成路線專屬）

- 生成 prompt **明文禁止圖內出現任何文字、字母、數字與標籤**：文字由後期標題／字幕圖層加入，畫面才會乾淨。
- 檢查關卡不是「檢查有沒有亂字」，而是「圖內不應有字，有即重生成」。
- 此原則與保留路線不衝突：保留路線是「既有文字不得抹除」；生成路線是「根本不生文字」。

## 生成後檢查清單

逐張放大目視：

| 檢查項 | 不合格情形 |
|---|---|
| 無文字 | 圖內有任何字母／數字／標籤 |
| 風格一致 | 線條粗細、配色、比例與基準圖明顯偏差 |
| 元件獨立 | 元件之間互相遮擋，或主體被邊框切掉 |
| 主體完整 | 物件缺角、變形、多餘殘影 |
| 解析度與留白 | 邊緣糊、主體貼邊無緩衝 |

## 手部素材生成與 nib 標定

手部屬可重建素材，不必仰賴舊檔：

1. 用 `--transparent` 生成「手持白板筆、筆尖明確」的透明底手部圖。**建議膚色填色**（如 warm skin tone, flat color fill）而非純線稿——純線稿手在揭露中的圖上會像幽靈；若生成結果內部仍透明，需洪水填充內部為實心再使用。
2. 手部尺寸約畫布高度的 35–40%（1080 高約 380–430px 寬）；過大會搶走畫面焦點。
3. 視覺確認筆尖像素位置，記入素材庫登記檔（本地座標 `nib:[x,y]`、圖片尺寸、生成 prompt、SHA-256）。
4. 合成時以 nib 點對齊遮罩前緣，不以圖片左上角猜筆尖。**素材任何變更（重新生成、裁切、縮放、內部填充）都必須重新標定 nib**。

## 誠實條款

- 生成的圖是點陣圖，reveal 是遮罩揭露，**不是取得原始筆畫順序**；需要真實逐筆時改走向量製作線。
- 生圖成本與次數向使用者透明：重生成達上限就回報，不默認重複扣費。
- 生成過程與每次不合格原因記錄在專案內，方便局部重做。
