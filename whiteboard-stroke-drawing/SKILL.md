# 白板動畫製作線：逐筆繪製

建立**獨立元件 → 明確筆畫順序 → 筆尖沿線條繪製**。此技能可單獨交給不同AI Agent，使用其可用的生圖、向量、影片與HTML工具；不依賴其他技能、平台API或本機固定路徑。它是Agent的操作規格，不是自帶模型及渲染器的應用程式。

## 接收與確認

- 讀實際腳本、參考圖與已有音訊。補問必要的觀眾／目的、目標片長（約略或硬性）、畫風、聲音、比例與交付範圍；已有資訊不重問。
- 明確選定「保持參考造型描線」或「建立新的簡潔向量造型」。使用者提供正式圖時，沒有重設授權就保留外觀；不得因路徑易控制而偷偷換風格。
- 未定可建議繁體中文、台灣女聲 `zh-TW-HsiaoChenNeural`、1920×1080、30fps。確認可用工具，不能保證特定TTS在所有環境可用。
- 技能名稱不是畫風；正式元件前固定角色比例、線條、配色與細節程度。需要配音時，先有可連續朗讀的旁白，字卡不是完整旁白。

## 執行

1. **腳本與分鏡**：整理旁白、字卡與來源標示。每幕按事件拆節拍及所需姿勢／道具，不把幕數當成素材數。先做粗配置，檢查位置、附著關係、敘事焦點與閱讀時間。已有授權的自動模式自行檢查修正，不另加每幕核准。
2. **獨立元件**：讀 [references/strokes.md](references/strokes.md)。建立或沿參考圖整理無新增內嵌文字的角色、道具、背景元件；文字另行加入。固定人物造型，一種姿勢一個ID，重用元件不重生。
3. **筆畫與預演**：為元件建立真實路徑、順序、抬筆及填色時機；先測一個代表性元件與短段落。PNG看起來像線稿不等於已取得筆畫；沒有路徑就整理或說明限制，不冒充逐筆。
4. **配音與正式時間**：生成或沿用語音，按實際句／詞邊界建立SRT及正式時間軸。旁白說到哪個概念，繪製對應物件；畫完留停留。不用大幅加速語音或亂跳筆尖去硬塞片長。
5. **繪製與合成**：按弧長逐步畫出線條，筆尖用同一路徑及座標變換，換筆畫抬筆。線條、填色、後製文字、手部及字幕分層。讀 [references/media-ebook.md](references/media-ebook.md) 完成媒體與選定的電子書。
6. **驗收**：依 [references/project-format.md](references/project-format.md) 記錄元件及時間，執行 `python scripts/check_project.py <project-dir>`；另實際觀看路徑順序、筆尖貼合、填色與轉場，完整解碼驗證成片。

## 界線與偏好

- 向量造型是可選視覺方式，不能默認替代使用者正式插畫。描線可能失去細節，需明確說明取捨並尊重既有授權。
- 自動描邊產生的碎線需整理順序；不能把雜亂路徑隨機跑一遍當自然手繪。SVG也未必自帶合理筆畫順序。
- **真正逐筆**是沿幾何線條增加長度；用寬筆刷掃過整張點陣圖是reveal，應改用保留原圖製作線或準確標示混合模式，勿混淆交付。
- 物件繪製完成後可原位停留。元件位移、姿勢替換、鏡頭及骨架動畫分開記錄；後者不是本製作線必然附帶的功能。
- 預設不顯示頁數、底部分段線。有分章才加獨立章節頁，且影片章節頁計入片長；電子書可另分章。
- 保留元件與成片版本。局部修改先辨識是全部引用或單幕修改，只重做受影響的元件、路徑、排版或時段。

## 可攜交付

依範圍交付MP4、SRT、旁白稿／音訊、可選單檔HTML、元件SVG／透明預覽、逐筆路徑JSON、共用時間軸、實際渲染程式／指令與驗證紀錄。外部生圖包模式只交付提示詞、ID與回傳規格，不擅自生成影片。所有路徑相對專案，必要字型／手部與來源要能追蹤；不包入帳密或機器快取。
